## How to use the glossary

Short definitions of the terms you will meet in this compendium and on the air, in alphabetical order. Terms that have their own article are links: follow one when the one-line definition is not enough. For on-air shorthand such as 73 or OM, see <Ref to="ham-abbreviations" />; for Q-codes, see <Ref to="q-codes" />; for formulas, see <Ref to="formula-sheet" />.

## A to D

| Term | Meaning |
|---|---|
| **<Ref to="ac-dc-and-waveforms">AC</Ref>** | Alternating current: current that reverses direction many times a second, as in household power and in radio signals. |
| **<Ref to="logging-and-qsl">ADIF</Ref>** | Amateur Data Interchange Format: a plain-text file format for exchanging log data between programs. |
| **<Ref to="agc-and-noise-reduction">AGC</Ref>** | Automatic gain control: a receiver circuit that turns the gain down on strong signals to keep the audio level steady. |
| **<Ref to="amplitude-modulation">AM</Ref>** | Amplitude modulation: information carried by varying the strength of the carrier. |
| **<Ref to="amplifiers">Amplifier</Ref>** | A circuit that makes a signal stronger by drawing power from a supply. |
| **<Ref to="how-antennas-work">Antenna</Ref>** | The conductor system that turns RF current into radio waves, and radio waves back into current. |
| **<Ref to="antenna-tuners">Antenna tuner</Ref>** | A matching network between radio and feed line that presents the radio with the impedance it wants. It does not change the antenna itself. |
| **<Ref to="aprs">APRS</Ref>** | Automatic Packet Reporting System: position, weather and short messages sent by packet radio. |
| **<Ref to="ares-and-races">ARES</Ref>** | Amateur Radio Emergency Service: volunteer operators who support emergency response, sponsored by the ARRL. |
| **<Ref to="clubs-and-elmers">ARRL</Ref>** | The American Radio Relay League: the US national amateur radio association, which represents US operators and publishes handbooks and a band plan. |
| **<Ref to="attenuators">Attenuator</Ref>** | A circuit that reduces signal level by a fixed or adjustable amount while keeping the impedance matched. |
| **<Ref to="wire-gauge-and-fusing">AWG</Ref>** | American Wire Gauge: the wire-size numbering in which a smaller number means thicker wire. |
| **<Ref to="baluns-and-ununs">Balun</Ref>** | A device that joins a balanced antenna or line to an unbalanced one (coax), such as a dipole to coax. |
| **<Ref to="amateur-band-chart">Band</Ref>** | A range of frequencies allocated for a service, such as the 20-meter amateur band. |
| **<Ref to="band-plans">Band plan</Ref>** | A voluntary agreement on which modes use which parts of a band. |
| **<Ref to="bandwidth-and-data-rate">Bandwidth</Ref>** | The width of spectrum a signal occupies, or a filter or antenna passes, in hertz. |
| **Beacon** | A station that transmits a repeating identification or signal so others can judge propagation. |
| **<Ref to="q-codes">Break-in (QSK)</Ref>** | Operating so you can hear the other station between your own CW characters. |
| **<Ref to="call-signs">Call sign</Ref>** | The unique identifier assigned to a licensed station, made of a prefix, a number and a suffix. |
| **<Ref to="capacitance">Capacitance</Ref>** | The ability to store energy in an electric field, measured in farads. |
| **<Ref to="modulation-basics">Carrier</Ref>** | The steady radio-frequency signal that is varied (modulated) to carry information. |
| **<Ref to="cat-control">CAT</Ref>** | Computer Aided Transceiver control: a link that lets software control a radio's frequency, mode and more. |
| **<Ref to="characteristic-impedance">Characteristic impedance</Ref>** | The impedance a transmission line presents to a signal travelling along it, set by its geometry (Z0). |
| **<Ref to="coaxial-cable">Coaxial cable</Ref>** | A feed line with a center conductor inside an insulator, surrounded by a shield. |
| **<Ref to="common-mode-chokes">Common-mode current</Ref>** | Current flowing in the same direction on both conductors of a line, or on the outside of coax, where it should not. |
| **<Ref to="control-operators">Control operator</Ref>** | The licensed amateur designated to be responsible for a station's transmissions. |
| **<Ref to="ham-abbreviations">CQ</Ref>** | A general call meaning: calling any station. |
| **<Ref to="squelch-and-tones">CTCSS</Ref>** | Continuous Tone-Coded Squelch System: a sub-audible tone that opens a repeater (the PL tone). |
| **<Ref to="what-is-cw">CW</Ref>** | Continuous wave: Morse code sent by turning a carrier on and off. |
| **<Ref to="decibels">dB</Ref>** | Decibel: a logarithmic ratio. 3 dB is double the power, 10 dB is ten times. |
| **<Ref to="gain-and-directivity">dBi</Ref>** | Antenna gain in decibels compared with an isotropic radiator. A dipole is 2.15 dBi. |
| **<Ref to="ac-dc-and-waveforms">DC</Ref>** | Direct current: current that flows in one direction only. |
| **<Ref to="frequency-modulation">Deviation</Ref>** | How far an FM signal's frequency swings away from the carrier frequency. |
| **<Ref to="digital-modes-overview">Digital mode</Ref>** | A mode that sends data as discrete tones or phase shifts, usually with a computer: FT8, PSK31, RTTY. |
| **<Ref to="half-wave-dipole">Dipole</Ref>** | An antenna of two equal conductors fed at the center between them; the half-wave dipole is the reference for dBd. |
| **<Ref to="satellite-operating">Doppler shift</Ref>** | The change in received frequency caused by relative motion, important for satellite work. |
| **<Ref to="dsp-basics">DSP</Ref>** | Digital signal processing: filtering and demodulating with mathematics instead of analog parts. |
| **<Ref to="dummy-loads">Dummy load</Ref>** | A resistor that absorbs transmitter power without radiating it, for testing. |
| **Duty cycle** | The share of time a transmitter is on; it determines average power. |
| **<Ref to="dxing">DX</Ref>** | A distant station; chasing such contacts is called DXing. |
| **<Ref to="awards">DXCC</Ref>** | DX Century Club: the ARRL award for confirming contacts with many countries and entities. |

## E to L

| Term | Meaning |
|---|---|
| **<Ref to="gain-and-directivity">EIRP</Ref>** | Effective isotropic radiated power: transmit power times antenna gain, compared with an isotropic antenna. |
| **<Ref to="clubs-and-elmers">Elmer</Ref>** | A mentor who helps newcomers learn the hobby. |
| **<Ref to="eme-moonbounce">EME</Ref>** | Earth-Moon-Earth: communicating by reflecting signals off the Moon, also called moonbounce. |
| **<Ref to="gain-and-directivity">ERP</Ref>** | Effective radiated power: transmit power times antenna gain, compared with a dipole. |
| **<Ref to="coaxial-cable">Feed line</Ref>** | The cable or line that carries RF between radio and antenna. |
| **<Ref to="impedance-and-radiation-resistance">Feed point</Ref>** | The place on an antenna where the feed line connects. |
| **<Ref to="frequency-modulation">FM</Ref>** | Frequency modulation: information carried by varying the carrier's frequency. |
| **<Ref to="frequency-and-wavelength">Frequency</Ref>** | The number of cycles per second, in hertz (Hz). |
| **<Ref to="radiation-patterns">Front-to-back ratio</Ref>** | The strength of an antenna's forward lobe compared with the opposite direction. |
| **<Ref to="ft8-and-ft4">FT8</Ref>** | A weak-signal digital mode using 15-second transmissions, widely used on HF. |
| **<Ref to="switches-relays-fuses">Fuse</Ref>** | A protective device that melts to open a circuit when current exceeds its rating; it protects the wire. |
| **<Ref to="gain-and-directivity">Gain</Ref>** | How much stronger a signal becomes, in an amplifier (more power) or an antenna (more focus). |
| **<Ref to="license-classes">General</Ref>** | The middle US license class, with most HF privileges. |
| **<Ref to="grey-line-and-long-path">Grey line</Ref>** | The band around the Earth between day and night, where HF propagation is often enhanced. |
| **<Ref to="radials-and-ground-planes">Ground plane</Ref>** | A conducting surface or set of radials that a vertical antenna works against. |
| **<Ref to="ground-wave">Ground wave</Ref>** | A signal that follows the Earth's surface rather than bouncing off the ionosphere. |
| **<Ref to="what-is-amateur-radio">Ham</Ref>** | A licensed amateur radio operator. |
| **<Ref to="clubs-and-elmers">Hamfest</Ref>** | A gathering with a swap meet, exams and talks for radio amateurs. |
| **<Ref to="harmonics-and-spurs">Harmonic</Ref>** | A multiple of a signal's frequency; unwanted harmonics from a transmitter must be filtered. |
| **<Ref to="frequency-and-wavelength">Hertz (Hz)</Ref>** | The unit of frequency: one cycle per second. |
| **<Ref to="radio-spectrum">HF</Ref>** | High frequency: 3 to 30 MHz, the shortwave range for worldwide communication. |
| **<Ref to="handheld-transceivers">HT</Ref>** | Handheld transceiver: a portable VHF/UHF radio. |
| **<Ref to="superheterodyne">IF</Ref>** | Intermediate frequency: the fixed frequency a superheterodyne receiver converts signals to for filtering and amplification. |
| **<Ref to="reactance-and-impedance">Impedance</Ref>** | Total opposition to AC, combining resistance and reactance, in ohms. |
| **<Ref to="inductance">Inductance</Ref>** | The ability to store energy in a magnetic field, measured in henries. |
| **<Ref to="ionosphere-layers">Ionosphere</Ref>** | The electrically charged upper atmosphere that reflects (refracts) HF radio waves. |
| **<Ref to="j-pole-and-slim-jim">J-pole</Ref>** | A simple half-wave antenna, end-fed through a quarter-wave matching stub, common on VHF and UHF. |
| **<Ref to="keys-and-paddles">Key</Ref>** | The switch used to send Morse code: straight key, paddle or bug. |
| **<Ref to="units-and-prefixes">kHz</Ref>** | Kilohertz: a thousand cycles per second. |
| **<Ref to="linear-amplifiers">Linear amplifier</Ref>** | An amplifier that raises power without distorting the signal, used for SSB and CW. |
| **<Ref to="grey-line-and-long-path">Long path</Ref>** | A signal that reaches you the long way around the Earth, rather than by the shortest route. |
| **<Ref to="logging-and-qsl">LoTW</Ref>** | Logbook of The World: the ARRL's online system for confirming contacts. |
| **<Ref to="single-sideband">LSB</Ref>** | Lower sideband: the SSB mode that keeps the sideband below the carrier. |
| **<Ref to="muf-and-luf">LUF</Ref>** | Lowest usable frequency: below it, signals are too weak to use, mainly from D-layer absorption. |

## M to R

| Term | Meaning |
|---|---|
| **<Ref to="mixers">Mixer</Ref>** | A circuit that combines two frequencies to produce their sum and difference. |
| **<Ref to="modulation-basics">Mode</Ref>** | The type of signal or emission: CW, SSB, FM, digital and so on. |
| **<Ref to="modulation-basics">Modulation</Ref>** | Putting information onto a carrier by varying its amplitude, frequency or phase. |
| **<Ref to="muf-and-luf">MUF</Ref>** | Maximum usable frequency: the highest frequency the ionosphere will return for a path. |
| **<Ref to="nets">Net</Ref>** | A scheduled, organized on-air gathering of operators. |
| **<Ref to="noise-and-snr">Noise floor</Ref>** | The level of background noise in a receiver; signals near or below it are hard or impossible to hear. |
| **<Ref to="nvis">NVIS</Ref>** | Near-vertical incidence skywave: steep-angle HF used for reliable regional contacts. |
| **<Ref to="ohms-law">Ohm (Ω)</Ref>** | The unit of resistance, reactance and impedance. |
| **<Ref to="open-wire-line">Open-wire line</Ref>** | A feed line of two parallel wires held apart by spacers, with very low loss; also called ladder line. |
| **<Ref to="oscillators">Oscillator</Ref>** | A circuit that generates a repeating signal at a set frequency. |
| **<Ref to="part-97-in-plain-words">Part 97</Ref>** | The FCC rules governing the Amateur Radio Service. |
| **<Ref to="ac-dc-and-waveforms">PEP</Ref>** | Peak envelope power: the average power during the strongest part of a modulated signal. |
| **<Ref to="phonetic-alphabet">Phonetic alphabet</Ref>** | Standard words for letters (Alfa, Bravo, Charlie) that make spelling clear over a radio link. |
| **<Ref to="dx-etiquette-and-split">Pileup</Ref>** | Many stations calling a rare or wanted station at the same moment. |
| **<Ref to="pll-and-synthesizers">PLL</Ref>** | Phase-locked loop: a circuit that locks an oscillator to a reference, the basis of frequency synthesis. |
| **<Ref to="polarization">Polarization</Ref>** | The orientation of a wave's electric field: horizontal, vertical or circular. |
| **<Ref to="skywave-and-skip">Propagation</Ref>** | The ways radio signals travel from one place to another. |
| **<Ref to="psk31">PSK31</Ref>** | A narrow, keyboard-to-keyboard digital mode using phase shifts at 31 baud. |
| **<Ref to="fm-voice">PTT</Ref>** | Push to talk: the switch or control that makes the radio transmit. |
| **<Ref to="resonance-and-q">Q</Ref>** | The quality factor of a resonant circuit: higher Q means a sharper, narrower response. |
| **<Ref to="q-codes">Q-code</Ref>** | A three-letter code starting with Q that stands for a phrase, such as QTH for location. |
| **<Ref to="qrp-radios">QRP</Ref>** | Low-power operation, commonly 5 watts or less. |
| **<Ref to="logging-and-qsl">QSL</Ref>** | A confirmation of a contact, or the card or electronic record that proves it. |
| **<Ref to="q-codes">QSO</Ref>** | A radio contact between two stations. |
| **<Ref to="radials-and-ground-planes">Radials</Ref>** | Wires laid on or above the ground to give a vertical antenna its counterpoise. |
| **<Ref to="reactance-and-impedance">Reactance</Ref>** | The opposition to AC offered by capacitors and inductors, in ohms. |
| **<Ref to="repeaters">Repeater</Ref>** | A station that receives on one frequency and retransmits on another, extending VHF/UHF range. |
| **<Ref to="resonance-and-q">Resonance</Ref>** | The frequency at which the inductive and capacitive reactance of a circuit cancel. |
| **<Ref to="electromagnetic-waves">RF</Ref>** | Radio frequency: alternating currents and fields at frequencies used for radio. |
| **<Ref to="rfi-and-emi">RFI</Ref>** | Radio-frequency interference: unwanted RF disturbing a receiver or electronic device. |
| **<Ref to="rit-xit-and-split">RIT</Ref>** | Receiver incremental tuning: shifts the receive frequency without moving the transmit frequency. |
| **<Ref to="signal-reports">RST</Ref>** | Readability, Strength, Tone: the signal report scale (phone omits the tone). |
| **<Ref to="rtty">RTTY</Ref>** | Radioteletype: the long-standing text mode that shifts between two tones. |

## S to Z

| Term | Meaning |
|---|---|
| **<Ref to="direct-conversion-and-sdr">SDR</Ref>** | Software-defined radio: a radio where most signal processing is done by software. |
| **<Ref to="single-sideband">Sidebands</Ref>** | The frequency bands above and below a carrier created by modulation. |
| **<Ref to="simplex">Simplex</Ref>** | Transmit and receive on the same frequency; used for direct contacts without a repeater. |
| **<Ref to="skin-effect">Skin effect</Ref>** | The tendency of RF current to flow near a conductor's surface. |
| **<Ref to="skywave-and-skip">Skip</Ref>** | The way HF signals return to Earth beyond the range of the ground wave; the area they miss is the skip zone. |
| **<Ref to="signal-reports">S meter</Ref>** | A receiver meter showing signal strength, where each S unit is 6 dB. |
| **<Ref to="solar-cycle-and-indices">Solar flux</Ref>** | A measure of solar radio noise at 10.7 cm that tracks HF conditions. |
| **<Ref to="summits-on-the-air">SOTA</Ref>** | Summits on the Air: an award program for operating from mountaintops. |
| **<Ref to="rit-xit-and-split">Split</Ref>** | Transmitting on a different frequency from the one you receive on. |
| **<Ref to="sporadic-e">Sporadic E</Ref>** | Patches of ionization in the E layer that briefly reflect VHF signals over long distances. |
| **<Ref to="squelch-and-tones">Squelch</Ref>** | A circuit that mutes the receiver until a signal is present. |
| **<Ref to="single-sideband">SSB</Ref>** | Single sideband: a voice mode that transmits one sideband and suppresses the carrier. |
| **<Ref to="superheterodyne">Superheterodyne</Ref>** | A receiver that mixes the incoming signal down to a fixed intermediate frequency. |
| **<Ref to="swr-and-reflections">SWR</Ref>** | Standing wave ratio: a measure of how well a load matches the feed line. 1:1 is a perfect match. |
| **<Ref to="license-classes">Technician</Ref>** | The entry-level US license class, with privileges on VHF/UHF and some HF. |
| **<Ref to="time-constants">Time constant</Ref>** | How quickly an RC or RL circuit charges or decays, equal to R × C or L ÷ R. |
| **<Ref to="transceiver-block-diagram">Transceiver</Ref>** | A radio that combines a transmitter and a receiver in one unit. |
| **<Ref to="tropospheric-propagation">Tropo</Ref>** | Short for tropospheric propagation: weather-driven bending of VHF/UHF signals beyond the horizon. |
| **<Ref to="tvi-and-consumer-electronics">TVI</Ref>** | Interference to television reception from a transmitter, extended to other consumer electronics. |
| **<Ref to="radio-spectrum">UHF</Ref>** | Ultra high frequency: 300 MHz to 3 GHz. |
| **<Ref to="baluns-and-ununs">Unun</Ref>** | An unbalanced-to-unbalanced transformer, used to change impedance. |
| **<Ref to="single-sideband">USB</Ref>** | Upper sideband: the SSB mode that keeps the sideband above the carrier. |
| **<Ref to="logging-and-qsl">UTC</Ref>** | Coordinated Universal Time: the worldwide time standard used for logs; also called Zulu. |
| **<Ref to="feed-line-loss">Velocity factor</Ref>** | How fast a signal travels in a line compared with free space, as a fraction (0.66 for solid-polyethylene coax). |
| **<Ref to="oscillators">VFO</Ref>** | Variable-frequency oscillator: the tunable oscillator that sets a radio's frequency. |
| **<Ref to="radio-spectrum">VHF</Ref>** | Very high frequency: 30 to 300 MHz. |
| **<Ref to="frequency-and-wavelength">Wavelength</Ref>** | The distance a wave travels in one cycle: 300 divided by frequency in MHz gives meters. |
| **<Ref to="winlink">Winlink</Ref>** | A radio email system with a global network of gateways. |
| **<Ref to="morse-alphabet">WPM</Ref>** | Words per minute: Morse speed, measured using the word PARIS. |
| **<Ref to="wspr">WSPR</Ref>** | Weak Signal Propagation Reporter: a mode for low-power propagation beacons. |
| **<Ref to="rit-xit-and-split">XIT</Ref>** | Transmitter incremental tuning: shifts the transmit frequency without moving the receive frequency. |
| **XYL** | Wife, in ham slang; YL is a young lady, or any female operator. |
| **<Ref to="yagi-uda">Yagi</Ref>** | A directional antenna with a driven element, a reflector and one or more directors. |
| **<Ref to="characteristic-impedance">Z0</Ref>** | Symbol for a transmission line's characteristic impedance, commonly 50 Ω in amateur radio. |
| **Zulu** | The military name for UTC, from the phonetic word for Z. |

<Callout kind="note" title="Terms vary a little">Some terms are used slightly differently in different places. A few, such as "DX", depend on where you are, and others, like "QRP", on whom you ask. The definitions here are the common amateur radio ones.</Callout>
